# 3-Minute Demo Script

Live AI stays **off** for a screen-share, so every click behaves the same.

| Time | Do this | Say this |
|---|---|---|
| 0:00 | Open **Journey simulator** with Greenline selected. Point at the trigger and the rhythm heatmap. | "Greenline is prequalified for a line of credit, and their forecast shows an $18K gap before Nov 20. The engine already knows when this owner engages: early mornings on weekdays." |
| 0:20 | Click **▶ Engaged path**. Pause when it reaches the landing-page miss. | "They clicked but left the landing page. That's a signal the message and page didn't answer their concern, so the engine flags the page for a test and switches to a cost message. It waits a day instead of following up immediately, because an instant follow-up would feel intrusive." |
| 1:00 | Let it reach the abandoned application. Open the **Decision trace**. | "Abandonment is a service moment, so cadence cost doesn't apply: one nudge right away, one reminder within 24 hours. Every option shows benefit minus cadence, fatigue and opt-out costs." |
| 1:30 | **Reset**, click **▶ Silent path**. | "Silence is a signal too. Each non-response lowers that channel's affinity, rotates the message, and moves in-product to a new surface. After three misses the engine stops and waits for a new need, because an unsubscribe would cost us the channel." |
| 2:00 | Click **▶ Risk event path**. | "A late payment overrides everything: promotion stops and the customer goes to Servicing." |
| 2:20 | Open **Experiments**. | "None of these numbers are guesses we keep. Each one is a test cell against a holdout. Here a cap of 3 beats 4 on net value once lost channels are priced in." |
| 2:45 | Open **Compliance check**, load **Approval promise**. | "And every message clears lending rules before it can send." |
| 3:00 | Close. | "This is the decision logic on synthetic data. With real behavioral signals and Data Science models, it scales." |
